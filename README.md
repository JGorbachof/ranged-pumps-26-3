# Ranged Pumps - Unofficial Port

A powered pump drains liquids across a configurable area.

Original: [raoulvdberge / Refined Mods](https://www.curseforge.com/minecraft/mc-mods/ranged-pumps) ([source](https://github.com/refinedmods/rangedpumps), upstream commit 13da16f526c5064f9f3d1d671982e6744dec470c). Maintained independently by Gorbachof.

## Install

Minecraft 26.3, NeoForge 26.3.0.118, Java 25. Place the JAR from [Releases](https://github.com/JGorbachof/ranged-pumps-26-3/releases) in the mods folder on client and server.

## Testing

Native server startup and pump energy use, fluid collection and source removal passed. Client rendering and extended gameplay remain unverified. This is an alpha release.

## Build

Use Java 25 and the included Gradle wrapper: gradlew.bat jar (Windows) or ./gradlew jar (Linux/macOS). The published binary includes the original license and NOTICE; packaging-only additions may differ from the native-tested build hash.
